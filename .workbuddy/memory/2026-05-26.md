# 工作记忆

## 2026-05-26

### 中俄文件认证网站搭建
- 用户：鸿宇，服务范围全国
- 目标：个人用户，在线服务平台，含在线客服
- 技术栈：Next.js 16 + TypeScript + Tailwind CSS v4 (Turbopack)
- 完成阶段：Phase 1 全部完成（项目脚手架 + 首页 + 所有核心页面 + 在线客服）

### 页面清单
- `/` 首页：Hero、数据展示、服务分类卡片、4步流程、Why Us、CTA
- `/services` 服务介绍：认证流程 + 各分类详细表格
- `/documents` 文件类型：分类筛选、搜索、文档卡片（含费用和材料）
- `/order` 在线办理：3步向导（选择文件→上传材料→确认支付）+ 提交成功页
- `/dashboard` 个人中心：订单列表 + 进度时间线
- `/faq` 常见问题：5个分类、可折叠问答

### 组件
- `Header`：响应式导航，移动端汉堡菜单
- `Footer`：4列布局，品牌信息+链接+联系方式
- `ChatWidget`：浮窗客服，预设常见问题，自动回复

### 数据层
- `src/data/services.ts`：3个分类（留学/婚姻/法律）、9种文件类型，含材料清单/费用/周期

### 设计风格
- 主色：蓝色（#1d4ed8），专业可信赖
- 点缀：红色（#dc2626）呼应俄罗斯元素
- 组件风格：大圆角卡片、扁平设计

### 个人账户系统 (Phase 2)
- **数据库**：JSON 文件数据库（`src/lib/db.ts`），存储于 `data/` 目录
- **认证**：自建 JWT + Cookie（`src/lib/auth.ts`），支持注册/登录/登出
- **密码加密**：bcryptjs
- **路由保护**：middleware.ts 拦截 `/dashboard` 和 `/order` 未登录请求

#### 新增 API 路由
- `POST /api/auth/register` — 用户注册
- `POST /api/auth/login` — 用户登录
- `POST /api/auth/logout` — 登出
- `GET /api/auth/me` — 获取当前用户
- `POST /api/orders` — 创建订单（含默认6步进度）
- `GET /api/orders` — 获取用户所有订单
- `GET /api/orders/[id]` — 获取订单详情

#### 新增页面
- `/login` — 登录页
- `/register` — 注册页
- Header 更新 — 显示登录状态、用户名、退出按钮
- Dashboard 更新 — 从 API 获取真实订单，空状态提示
- Order 更新 — 提交时 POST 到 API，显示提交中状态

#### 测试验证
- 注册、登录、创建订单、查看订单完整流程通过
- 路由保护：未登录访问 /dashboard /order 自动跳转 /login
